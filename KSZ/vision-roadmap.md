# 视觉回答路线与实施记录

## 本次：VLM 直接回答

状态：功能分支已实现并完成回归；尚未部署。

链路：图片＋用户问题＋绑定语言＋系统约束 → VLM 流式正文 → 小智分句 TTS。

核心实现属于独立 Museum Guide Agent 仓库。`VISION_ANSWER_MODE=direct` 为默认模式；`structured` 保留原有“VLM 识别 JSON → 藏品匹配 → 条件 RAG → 文本 LLM”流程作为回退。当前直接模式跳过识别、检索和第二次模型调用，不伪造藏品身份、置信度或知识命中。HTTP 格式、请求关联、取消、超时和 TTS 机制保持兼容。

## 后续：识别与知识增强

目标链路：图片 → YOLO/检测与具体藏品匹配 → 条件 RAG → 图片＋知识＋问题 → VLM 流式回答 → TTS。

- 通用 YOLO 提取类别/位置；具体藏品需训练、图像特征匹配或可信展区信息辅助。
- 可靠匹配才检索；未匹配、识别失败或超时直接看图回答。
- 识别与检索设置等待上限，最终仅由 VLM 生成答案。
- 本次不训练、不部署 YOLO，不实现新增 RAG 路径。

## 验证

验收覆盖一次 VLM 调用且无文本 LLM/RAG、首正文早于全文、多语言与系统约束、非流式兼容、取消/超时、异常清理与日志脱敏，以及 structured 回退回归。设备端拍照、上传完成和首音频播放尚需实际复测。
