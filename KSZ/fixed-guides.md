# 固定讲解播放

管理中心「场馆与区域 → 编辑场馆」统一选择 RAG、固定讲解或关闭信标讲解，场馆下所有区域、位置和信标继承该设置。关闭只取消自动播报，保留定位和主动问答。新场馆默认 RAG；管理端升级时执行 `alembic upgrade head`。原有一致的位置设置迁移至场馆；同一场馆内配置不一致时需先统一再升级。

固定讲解使用知识中心该场馆、该位置已发布的语音，按当前绑定角色（青年、儿童、专家）和语言（中、英、日、韩）选择版本，不读取生成中的草稿，不调用在线 TTS。未发布、版本缺失、音频读取或解码失败时，按「不可用时降级 RAG」开关决定是否调用原 RAG 讲解；关闭后停止本次播放，设备运行态 `last_error` 记录原因。

在小智 `KSZ/.env` 设置 `KSZ_RAG_API_URL`（RAG 根地址，不带 `/v1` 等路径）与 `KSZ_RAG_API_KEY`（具有对应场馆权限的检索密钥），重新创建 server 容器。Compose 已透传两项。读取 `/api/v1/guides` 时按管理端目录 `museum_code` 传场馆编号，同时传 `place_id`、`role` 和 `language`；下载音频同样使用服务端 Bearer 密钥。仅访问配置的 RAG 主机，不跟随重定向，不使用响应中的任意音频 URL。

更新管理端和发布讲解后，还须部署包含固定播放代码的小智 server 镜像；旧镜像会继续走 RAG。运行日志 `Fixed guide selected` 表示已命中固定版本，并列出角色、语言和段数；`Fixed guide unavailable` 包含失败原因及是否降级，先检查 RAG 地址、密钥场馆权限和对应位置是否已发布。只更新源码或 `.env`，不重新构建并创建 server 容器，不会生效。

音频字节通过已有 WAV/MP3/OGG 解码器转成设备协商采样率的 Opus/PCM，复用原有 TTS JSON 和音频下发通道。每次只播放一段；完成后将文本加入当前会话的 assistant 历史和上下文，并按原聊天记录配置上报智控台。未播放的后续段落不提前加入历史，每天输出额度与普通聊天共用。

按键打断、语音新提问和断线会取消播放。新提问优先进入普通问答；当前连接内说「继续讲解」「接着讲」或对应的四语继续命令，接着播放未完成段落，跳过已完成段落。恢复复用最初读取的发布文本，不重新翻译或合成。切换位置、角色、语言或连接后不恢复旧位置的音频。

每段使用独立 `response_id` 和完整的 start／音频／stop 周期，明确段落结束边界。支持 `hello.features.playback_progress` 的固件按[播放回执协议](narration-playback.md#固件播放回执)报告 `played` 或 `finished`（该段 `played_through=1`），收到回执后才提交历史和游标。未声明能力的旧固件按原音频发送队列排空及预缓冲等待判断段落完成，无法确认扬声器逐字进度。两种情况都会重播被打断的当前段，不承诺从字词或毫秒断点恢复。回执超时停止并保留当前段，可重新请求继续。

只播放前两段且运行态显示 `position_expired` 时，先检查设备是否在播放期间持续上报真实信标观测。默认位置有效期为 15 秒，固件应按下发策略每 5 秒续报当前稳定信标；普通在线心跳不会续期位置。旧固件可先沿用 `device_event/beacon_change` 实现定时续报，具体报文和防抖要求见[旧固件兼容](guide-protocol.md#旧固件兼容)，不必为连续播放先启用 `playback_progress`。设备真正实现回执之前不要声明该能力，否则服务端将等待回执直至超时。

`server/tests/test_fixed_guides.py` 覆盖分段历史、普通追问与继续路由、打断、角色位置隔离、失败降级、已发布 API 鉴权和真实 WAV 解码。实体固件播放回执仍需设备联调。
